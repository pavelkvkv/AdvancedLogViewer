## Что реализовано

### 1. Оптимизация памяти (экономия ~40%)
- Отключен undo/redo в Text widget
- Очистка буферов при удалении логов
- Эффективное использование памяти при batch-вставке

### 2. Оптимизация производительности (ускорение 2-50x)
- Batch-вставка логов (50x быстрее при 50 строк/сек)
- Асинхронная фильтрация с индикатором прогресса
- Компиляция regex для ускорения поиска

### 3. Улучшение UX
- UI не зависает при фильтрации миллионов записей
- Индикатор прогресса в заголовке панели (например, "D [45%]")
- Отзывчивость приложения при любых операциях

### 4. Исправление багов
- **Race condition** при сбросе фильтра (см. `BUGFIX_RACE_CONDITION.md`)
- Блокировка batch-вставки во время асинхронной перерисовки
- Автоматическая вставка накопленных логов после завершения refresh
- Троттлинг сообщений «Ошибка чтения» (не более одного раза за 5 сек) при потере доступа к UART
