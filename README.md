# Advanced Log Viewer

Продвинутый просмотрщик логов с поддержкой последовательной передачи данных (UART/Serial). Приложение позволяет одновременно отслеживать логи разных уровней в реальном времени с возможностью фильтрации, автоматической прокрутки и экспорта логов.

## Особенности

- 📊 **Четыре уровня логирования**: Debug, Info, Warning, Error
- 🔌 **UART/Serial поддержка**: Настраиваемая скорость передачи (115200, 4000000 и др.)
- 🎨 **Цветной интерфейс**: Визуально различные уровни логов
- 🔍 **Фильтрация**: Независимые фильтры для каждой панели логов
- 📝 **Сохранение логов**: Автоматическое сохранение в файлы по уровням
- 🎛️ **Управление панелями**: Сворачивание/разворачивание для удобства
- ⚙️ **Конфигурация**: Сохранение настроек в `settings.ini`

## Требования

- Python 3.7+
- Необходимые пакеты (см. `requirements.txt`)

## Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
python AdvancedLogViewer.py
```

## Сборка бинарника

Проект использует **PyInstaller** для создания автономного исполняемого файла.

### Быстрая сборка

```bash
pyinstaller AdvancedLogViewer.spec
```

Бинарник будет создан в папке `dist/`.

### Подробная инструкция

Смотрите `BUILD.md` для полной информации о процессе сборки, оптимизации и решении проблем.

## Конфигурация

Файл `settings.ini` содержит основные настройки:

```ini
[Connection]
port = /dev/ttyACM0
baudrate = 4000000
```

- **port**: COM-порт для подключения (Linux: `/dev/ttyACM0`, Windows: `COM3`)
- **baudrate**: Скорость передачи в бод
