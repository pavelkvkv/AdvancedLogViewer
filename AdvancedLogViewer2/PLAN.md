## Этап 1 — Ядро: хранение и маршрутизация

*Цель: `LogStore`, `LogDistributor`, `FilterEngine` работают и покрыты юнит-тестами.*

- [x] **1.1** Реализовать `LogStore` (чанковое хранилище, `QReadWriteLock`, `linesAppended` signal, ограничение по числу строк, вытеснение старых чанков) → [SPEC §5.2](SPEC.md#52-logstore)
- [x] **1.2** Реализовать `FilterEngine` — парсер синтаксиса фильтров, предикат `matches()`, thread-safe → [SPEC §8.1–8.2](SPEC.md#81-синтаксис-фильтра)
  - [x] **1.2a** Contains (подстрока, case-insensitive)
  - [x] **1.2b** Wildcard (`*`, `?`) через `QRegularExpression`
  - [x] **1.2c** `startswith()`, `endswith()`, `contains()` — функциональный синтаксис
  - [x] **1.2d** OR-объединение через `|`
- [x] **1.3** Реализовать `LogDistributor` — получение строк, прогон через глобальные фильтры, рассылка в `LogStore`-ы → [SPEC §5.3](SPEC.md#53-logdistributor)
- [x] **1.4** Написать юнит-тест (`QTest`): `LogStore` — добавление / вытеснение чанков / thread-safety (`std::jthread` + TSAN)
- [x] **1.5** Написать юнит-тест: `FilterEngine` — все виды синтаксиса + edge cases (пустой фильтр, регистр, спецсимволы regex)
- [x] **1.6** Написать юнит-тест: `LogDistributor` — дублирование строк в несколько `LogStore`-ов по глобальным фильтрам

**Ревью 1:** все юнит-тесты зелёные под TSan; clang-tidy чист.

- [x] **2.3** Декодирование по кодировке профиля (`utf8` / `cp1251` / `cp866`) → [SPEC §4.1](SPEC.md#41-структура-профиля-json)
- [x] **2.4** UART-backend (`QSerialPort`): подключение, чтение, фоллбек по таймауту 5 с → [SPEC §7.2](SPEC.md#72-uart-соединение)
