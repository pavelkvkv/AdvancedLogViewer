# Исправление бага: Race Condition при фильтрации

## Описание бага

**Симптомы**:
- При сбросе фильтра (очистка поля + Enter) панель очищается полностью или почти полностью
- Затем постепенно заполняется по мере прихода новых логов
- Происходит не во всех панелях сразу, а спорадически в одной
- Также триггерится при изменении формата времени (кнопки "Полное/Сократить/Скрыть")

**Причина**: Race Condition (гонка состояний)

```
Временная шкала бага:
T0: Пользователь нажимает Enter (сброс фильтра)
T1: refresh_text() очищает виджет (delete '1.0' END)
T2: _refresh_batch() начинает асинхронную перерисовку (по 5000 записей)
T3: ⚠️ Приходят новые логи
T4: ⚠️ _flush_inserts() вставляет новые логи В ОЧИЩЕННЫЙ виджет
T5: _refresh_batch() продолжает вставлять старые данные
T6: В итоге: старые данные перезаписывают новые, или наоборот
```

## Решение

Добавлен механизм блокировки batch-вставки во время refresh:

### 1. Флаг блокировки
```python
self._is_refreshing = False  # True во время refresh_text()
```

### 2. Логика в refresh_text()
```python
def refresh_text(self):
    self._is_refreshing = True  # Блокируем batch-вставку
    # ... очистка и перерисовка ...
    self._is_refreshing = False  # Разблокируем после завершения
    if self._pending_inserts:
        self._flush_inserts()  # Вставляем накопленное
```

### 3. Проверка в _flush_inserts()
```python
def _flush_inserts(self):
    if self._is_refreshing:
        # Откладываем вставку до завершения refresh
        self.after(50, self._flush_inserts)
        return
    # ... обычная вставка ...
```

## Результат

**До исправления**:
```
refresh_text()      _flush_inserts()
      |                   |
   clear() ────────────────┤
      |                insert() ← КОНФЛИКТ!
   batch()                 |
      |                    |
   batch()                 |
```

**После исправления**:
```
refresh_text()      _flush_inserts()
      |                   |
   clear()                |
_is_refreshing=True       |
      |              ✋ БЛОКИРОВКА
   batch()                |
      |                   |
   batch()                |
_is_refreshing=False      |
   flush_pending() ───► insert() ← ОК!
```

## Тестирование

**Воспроизведение бага (до исправления)**:
1. Запустить приём логов (50 строк/сек)
2. Накопить 10000+ строк
3. Применить фильтр (например, "error")
4. Очистить фильтр (пустое поле + Enter)
5. Баг: панель почти пустая, заполняется постепенно

**Проверка исправления**:
1. Те же шаги
2. Результат: панель корректно заполняется всеми логами
3. Новые логи добавляются после завершения refresh
